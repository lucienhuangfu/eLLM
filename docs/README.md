# 文档总览

这个文档目录按 vLLM 的组织方式重构，方便按“入门 / 使用 / 服务 / 配置 / 训练 / 部署”来浏览。

## Getting Started

- `getting_started/`：安装、启动和最小示例

## User Guide

- `usage/`：面向应用的使用说明
- `serving/`：服务、运行时和调度
- `configuration/`：配置与性能调优

## Developer Guide

- `models/`：模型相关说明
- `training/`：训练相关内容
- `deployment/`：部署指南
- `examples/`：示例
- `features/`：能力说明
- `api/`：接口文档
- `benchmarking/`：性能评测
- `cli/`：命令行工具
- `community/`：社区信息
- `contributing/`：贡献指南
- `governance/`：治理与发布
- `design/`：设计说明
- `mkdocs/`：文档站点配置

## 起点

- 如果你想先跑起来，去 `getting_started/`
- 如果你想看运行逻辑，去 `serving/`
- 如果你想调性能，去 `configuration/`
