- 每个算子目录采用固定命名约定：`generate_hf_<op>.py` + `<op>_alignment_test.rs` + `test_<op>_alignment.py` + `dump/` 子目录存放双方输出。
- 对齐判定统一使用三项指标：`max_abs < 1e-5`、`mean_abs < 1e-6`、`cosine > 0.999999`，失败时打印前 10 个元素逐位差异以便定位。
- dump 文件路径一律基于 `Path(__file__).parent / "dump"` 解析，避免硬编码绝对路径。
- Rust 输出与 Python 参考输出分别保存为 `rust_<op>*` 与 `python_<op>*` 前缀的 `.bin`/`.npy` 文件，便于区分来源。
- 端到端脚本通过 `argparse` 暴露 `--dump-dir`、`--skip-*`、`--hf-dtype` 等开关，允许分阶段执行 dump/rust/compare。
