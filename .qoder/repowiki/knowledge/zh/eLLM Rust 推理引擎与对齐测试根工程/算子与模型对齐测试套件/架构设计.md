本模块按「算子/模型」维度组织为并列子目录（rope、silu_mul、rms_map、moe_router、matmul3、qwen3_moe、tokenizer），每个子目录遵循统一模板：
- `generate_hf_<op>.py`：用 PyTorch/HF 生成参考输入/输出并写入 `<op>/dump/`；
- `<op>_alignment_test.rs`：Rust 侧调用被测算子，将结果以 `.bin`/`.npy` 写回同一 dump 目录；
- `test_<op>_alignment.py`：加载双方 dump 文件，使用 `max_abs < 1e-5`、`mean_abs < 1e-6`、`cosine > 0.999999` 三指标判定 PASS。
顶层提供共享工具 `alignment_utils.py`（compare_arrays / load_npy / save_npy / get_dump_dir）和脚手架脚本 `scripts/create_new_operator.py`，后者会按上述约定自动生成新算子骨架。
针对端到端场景，`tokenizer/` 下脚本负责从 HF 模型导出每层中间张量（`dump_hf_layer_outputs.py`）、Rust 侧对应二进制（`multi_batch_alignment.rs` 等），再由 `compare_layers.py` 按层比对并在首次失配处展开到组件级（post_input_norm / attn_residual / post_attn_norm / mlp_output）。`qwen3_moe/run_alignment.py` 作为编排入口，依次调用 tokenizer dump → cargo run qwen3_one_token_alignment → compare_layers，支持 `--skip-hf/--skip-rust/--skip-compare` 分段执行。依赖仅 numpy/torch，Rust 侧通过 `cargo run --bin <name>` 直接编译运行。
