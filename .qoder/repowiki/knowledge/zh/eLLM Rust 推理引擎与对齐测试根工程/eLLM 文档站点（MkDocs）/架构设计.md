纯静态文档仓库，使用 MkDocs 作为站点生成器，通过根级 `docs/.nav.yml` 声明导航树（Getting Started / User Guide / Developer Guide 三大分区）。内容按主题拆分为子目录：`getting_started/`（安装与快速开始）、`usage/`（v1 使用指南）、`serving/`（在线/离线推理与 OpenAI 兼容服务）、`configuration/`（环境变量与优化）、`cli/`（各命令参考）、`benchmarking/`（基准测试）、`design/`（运行时、算子、Transformers 内部设计）、`contributing/`（模型贡献流程与 CI）、`deployment/`、`features/`、`integrations/`、`governance/`、`reference/glossary.md`。`docs/index.md` 同时提供中英文首页与本地预览说明（`mkdocs serve`），当前处于从单文件向 MkDocs 友好小文件迁移阶段。
